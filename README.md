# Bootcamp JS 2 - Laboratorio Modulo 9.1 - Ticket de compra

Ejercicio del Modulo 9 para calcular el resultado final de un ticket de compra.

## Objetivo

La funcion `calculaTicket` recibe lineas de ticket con producto y cantidad, y devuelve:

- Lineas con nombre, cantidad, precio sin IVA, tipo de IVA y precio con IVA.
- Totales sin IVA, con IVA y total de IVA.
- Desglose de IVA por tipo.
